SafeDrones
==========

SafeDrones is a framework for reliability and safety modelling and evaluation
of multicopters (multi-rotor drones) and electric-powered vertical take-off and
landing (eVTOL) aircraft.

Installation
------------

Clone the repository and install it with pip:

.. code-block:: console

   git clone https://github.com/Dependable-Intelligent-Systems-Lab/SafeDrones.git
   cd SafeDrones
   python -m pip install .
